# 人工 UI 评审与视觉回归

- ID：ui-visual-review。
- 环节：UI / 测试。
- 卡片版本：0.1；来源核对：2026-10-24。
- 状态：候选，未实测。

用途：让 UI 修改有页面对比证据，同时保留人工对主流程、可读性和信息层级的判断。

条件：有可启动页面、确定路由、合成数据与可重复的截图环境。Playwright、浏览器、操作系统、字体、视口与主题版本尚未选定，复现前须记录。

## 候选步骤

1. 选定主流程及空、加载、成功、错误和权限受限状态。
2. 固定环境，以合成内容生成截图。
3. 人工检查主流程、正文可读性和提示，修正后复核再建立基线。
4. 后续修改生成差异图，人工解释变化；独立执行功能测试。

验收：关键操作可完成；不靠缩小字号塞内容；必要错误与权限提示清楚；已指出问题完成修正复核。自动更新基线不能代替审查。

局限：相同截图不证明业务正确，差异不必然是缺陷。运行环境可能影响渲染。无公开实测证据，不宣称已验证。
