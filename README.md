# 可复用工程实践库

先复现已经跑通的能力，再做业务定制。

这里整理跨项目可复用的工程原则、交接格式、候选方案和公开来源。首版为文档与空白模板，不含可运行产品、部署脚本或第三方源码。

## 开始使用

1. 明确目标项目的需求、范围和验收标准。
2. 阅读 [项目原则模板](templates/AGENTS.md) 和 [交接模板](templates/HANDOFF_STATUS.md)，按目标项目事实核验填写，不直接覆盖已有规则。
3. 从 [方案卡模板](templates/practice-card.md) 和 [候选索引](references/candidates.md) 选择最小能力。
4. 在隔离环境用合成数据复现，记录版本和证据，再进行业务定制。

模板被复制或读取不代表自动生效，也不授予新的权限。根目录 AGENTS.md 仅约束本公开文档库维护，与目标项目模板分开。

## 工程环节

- UI 与交互：结构、主流程、状态、人工评审与视觉回归。见 [UI 候选卡](practices/ui/visual-review.md)。
- 后端与数据：接口契约、对象权限、字段、迁移与恢复，使用方案卡逐项记录，当前无已复现条目。
- Agent 与 Skill：输入输出、工具权限、失败处理、评测与接管。先看 [外部候选](references/candidates.md)。
- 测试与 CI/CD：分层验证、依赖版本、审查和发布检查。
- 部署与运维：构建来源、环境隔离、健康检查与恢复。见 [部署候选卡](practices/deployment/versioned-release.md)。

## 验证状态

- 候选：有来源或明确设计，未完成独立复现。
- 已复现：有确定版本、环境、步骤与可核对的最小复现证据。
- 已验证流程：在声明范围内完成验收，有对应版本证据和局限说明。
- 待复核：依赖或环境变化，旧证据不能直接用于当前版本。
- 已弃用：保留原因与替代方向。

首版没有“已验证流程”条目。网页可访问不代表登录、AI 或完整业务流程通过；构建和自动测试也不能代替实际 UI 验收。
